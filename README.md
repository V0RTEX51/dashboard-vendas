# Painel de Vendas

Dashboard de vendas com indicadores, gráficos interativos e filtros. Mostra rápido como o negócio está indo e o que está vendendo mais.

Projeto de demonstração. Os dados são fictícios, gerados de forma determinística (sempre os mesmos) para a demo funcionar sem servidor.

## Funcionalidades

- **Indicadores:** receita, pedidos, ticket médio e unidades, com variação em relação ao período anterior.
- **Gráficos:** receita mensal, receita por categoria e por região.
- **Filtros:** período (3, 6 ou 12 meses), região e categoria. Tudo é recalculado na hora.
- **Tabela de produtos:** ordenável por qualquer coluna, com participação na receita.
- **Exportação:** CSV com as vendas filtradas.
- Tema claro e escuro, layout responsivo.

## Tecnologias

HTML, CSS, JavaScript e [Chart.js](https://www.chartjs.org/).

## Rodar localmente

Abra o `index.html` no navegador.
